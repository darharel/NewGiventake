# GivenTake MVP

GivenTake is a mobile-first barter marketplace MVP built with React, Vite, Express, and SQLite-like local persistence via `sql.js`.

## Stack
- React
- Vite
- Express
- sql.js

## Features
- Hebrew-first onboarding
- Email/password authentication
- Profile, interests, and wishlist
- Discover feed with filters
- Item creation and management
- Favorites
- Trade offers and inbox
- Trade chat and notifications
- Basic admin overview

## Local Run
```bash
npm install
npm run dev
```

Client:
- `http://127.0.0.1:5176/` during the current local run

API:
